# Medical AI & Computer Vision Journey (120 Days) 🧠💻

Welcome to my intensive 120-day roadmap focused on **Artificial Intelligence, Data Mining, and Medical Image Processing**.

## 📅 Progress Log
- **Day 01:** Learned 3D medical image representation (Matrices & Tensors), Pixel Normalization, and implemented automated 3D MRI tumor slice detection using `NumPy`.
- **Day 02:** Implemented medical data cleaning with `Pandas`, handling extreme outliers (`Age > 120`) and imputing missing clinical values (`NaN`) using `Median` statistics.
- **Day 03:** Built supervised disease classification models (`DecisionTreeClassifier`, `RandomForestClassifier`) with `train_test_split` and evaluated diagnostic safety using `Confusion Matrix` and `Recall`.
- **Day 04:** Implemented probabilistic risk scoring (`LogisticRegression` & `predict_proba`) and customized clinical decision thresholds (`0.35`) to catch borderline patients.
